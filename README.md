# Парсер Яндекс.Карт — организации без сайта

Ищет по Яндекс Картам фирмы по запросу и городу и сохраняет **только те, у кого
нет своего сайта** — готовая база для холодных продаж: название, адрес, телефоны,
рейтинг, часы работы и ссылка на карточку.

Ни API-ключей, ни регистрации, ни браузера: Яндекс отдаёт результаты поиска
«на сервере», данные лежат в JSON внутри HTML-страницы. Программа читает их
обычным HTTP-запросом и листает выдачу с вежливыми паузами.

## Скачать

Готовый файл для Windows (Python и Node.js не нужны):

**[yandex-maps-parser.exe](./dist/yandex-maps-parser.exe)** — просто положите
куда удобно и запускайте из консоли.

## Использование

```bat
yandex-maps-parser.exe -q стоматология -c Тула
```

Что появится рядом с программой: `results.csv` (открывается двойным щелчком в
Excel) и — если добавить `--json` — `results.json`.

### Команды

| Ключ | Что делает |
|---|---|
| `-q, --query <текст>` | **обязательный**: что ищем — «стоматология», «автосервис», «кафе»… |
| `-c, --city <город>` | город (рекомендуется): «Тула», «Москва»… |
| `-n, --max-pages <N>` | сколько страниц выдачи листать, 1 страница = 25 фирм (по умолчанию 10) |
| `-o, --out <файл>` | файл CSV (по умолчанию `results.csv`) |
| `--json` | дополнительно записать JSON |
| `--all` | не фильтровать: сохранить всех, колонка «Сайт» покажет, у кого сайт есть |
| `--no-city-filter` | не отсекать организации из соседних городов |
| `--delay <мс>` | пауза между страницами (по умолчанию 1500 мс) |
| `--file <html>` | разобрать сохранённую страницу вместо сети (проверка формата, офлайн) |
| `-h, --help` | справка |

### Примеры

```bat
:: база стоматологий Тулы без сайта
yandex-maps-parser.exe -q стоматология -c Тула

:: салоны красоты Москвы, 20 страниц (до 500 фирм), CSV + JSON
yandex-maps-parser.exe -q "салон красоты" -c Москва -n 20 -o salons.csv --json

:: автосервисы Казани — все сразу, без фильтра по городу
yandex-maps-parser.exe -q "автосервис" -c Казань --all --no-city-filter
```

## Что в результате

CSV-колонки: Название, Адрес, Телефоны, Оценка, Отзывов, Фото, Категории,
Часы работы, Сеть, Карточка подтверждена, Сайт, Широта, Долгота,
Ссылка на карточку, Город, Запрос, Дата сбора.

По умолчанию в файл попадают **только фирмы без сайта**. Сайт определяется
по всем полям карточки сразу (`urls`, `businessLinks`, `socialLinks`), при этом:

- ссылки на VK, Telegram, WhatsApp, 2ГИС, Дзен и подобные **сайтом не считаются** —
  это ровно те фирмы, которым сайт нужен;
- адрес без схемы (`dentservis-tula.ru`) тоже распознаётся как сайт;
- если у фирмы несколько телефонов, дубли (включая тот же номер из WhatsApp)
  убираются.

## Как это работает

1. Запрос вида `https://yandex.ru/maps/?text=<запрос>+<город>&page=N`.
2. Из страницы берётся самый большой `<script type="application/json">` —
   состояние выдачи; список фирм лежит в `stack[0].results.items`
   (25 организаций на странице, контакты уже в выдаче).
3. Каждая организация нормализуется, отсеиваются подборки, транспорт и чужие
   города; сайт ищется во всех полях ссылок.
4. Пагинация идёт, пока приходят новые фирмы; пауза между страницами —
   от 1,5 с (настраивается `--delay`).

Формат проверен по двум независимым открытым проектам (октябрь 2025 — май 2026):
[krein15/maps-parser](https://github.com/krein15/maps-parser) и
[volk6022/Atomic-Scraper-Service](https://github.com/volk6022/Atomic-Scraper-Service).
Если Яндекс изменит формат, программа честно напишет об этом и не будет
выдумывать данные.

## Ограничения

- **Капча.** При слишком частых запросах Яндекс может показать SmartCaptcha.
  Программа не обходит её — сделайте паузу (несколько минут) и запустите снова.
  Держите `--delay` не меньше 1500 мс.
- **Объём.** Выдача Яндекса листается, пока приходят новые фирмы; оценка
  `totalResultCount` ненадёжна. Если программа написала «выдача не
  исчерпана» — увеличьте `--max-pages`.
- **Данные — только публичные сведения, которые фирмы сами разместили на
  карте.** Используйте базу для деловой переписки, не для спама, и
  соблюдайте условия использования Яндекса.

## Разработка

```bash
npm install        # зависимости для сборки exe
npm test           # 25 проверок: разбор страницы, фильтр «без сайта», CSV
npm start -- -q кафе -c Тула --file fixtures/yandex_search.html   # офлайн-прогон

# пересобрать exe для Windows (нужен Bun >= 1.1)
bun build --compile --target bun-windows-x64 src/index.js --outfile dist/yandex-maps-parser.exe
```

Структура:

```
src/index.js    CLI: аргументы, вывод CSV/JSON, итоги
src/parser.js   разбор страницы Яндекса, фильтры, листание с паузами
src/csv.js      CSV с BOM и разделителем «;» (Excel)
fixtures/       сохранённая страница выдачи для тестов
test/           тесты (node test/run-tests.js)
```
