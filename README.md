# Прокси для Telegram на Windows

Приложение с графическим интерфейсом запускает локальный SOCKS5-прокси через SSH. Нужен **свой доступный SSH-сервер** с доступом к Telegram и разрешённым TCP forwarding. Приложение не предоставляет сервер и не гарантирует обход блокировки, в частности если SSH-сервер недоступен из вашей сети.

## Готовый EXE

Откройте вкладку **Actions** репозитория → **Build Windows app** → успешный запуск → скачайте артефакт **TelegramProxy-Windows**. Распакуйте архив и запустите `TelegramProxy.exe`. Для скачивания артефактов может потребоваться вход в GitHub. Если запуска ещё нет, запустите workflow вручную через **Run workflow**, выбрав ветку проекта. EXE собирается GitHub Actions; он не хранится в репозитории.

1. Введите адрес сервера, имя пользователя SSH и, если нужно, порты. Нажмите **Подключить**.
2. В отдельном окне SSH при первом подключении сверьте отпечаток ключа сервера по доверенному каналу и подтвердите его; введите пароль или парольную фразу ключа, если потребуется. Не подтверждайте неизвестный ключ вслепую.
3. В Telegram Desktop откройте **Настройки → Продвинутые настройки → Тип подключения**, добавьте SOCKS5 с сервером `127.0.0.1` и локальным портом из приложения (по умолчанию `1080`). Поля логина и пароля прокси оставьте пустыми. Telegram нужно настроить вручную: приложение не изменяет его настройки.
4. Держите приложение открытым. Нажмите **Отключить**, чтобы остановить туннель. Если SSH отключится, подключитесь снова.

На Windows нужен установленный **OpenSSH Client** (Дополнительные компоненты Windows). Статус запущенного прокси означает, что локальный порт открыт, а не гарантирует доступность Telegram. Пароли приложение не сохраняет; проверка SSH-ключа использует стандартное поведение OpenSSH.

## Запуск из исходников

Установите Python с поддержкой tkinter, затем запустите `py telegram_gui.py`. Дополнительные Python-библиотеки для запуска не требуются.

## Сборка вручную

В PowerShell: `py -m pip install pyinstaller`, затем `py -m PyInstaller --noconfirm --clean --onefile --windowed --name TelegramProxy telegram_gui.py`. Готовый файл появится в `dist/TelegramProxy.exe`.
